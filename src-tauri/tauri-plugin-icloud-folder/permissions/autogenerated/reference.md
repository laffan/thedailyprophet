## Default Permission

Default permissions: allow the full folder-bookmark demo flow (pick, resolve, list, read, write, stop).

#### This default permission set includes the following:

- `allow-pick-folder`
- `allow-resolve-bookmark`
- `allow-materialize-folder`
- `allow-stop-access`
- `allow-start-watch`
- `allow-stop-watch`
- `allow-reveal-in-files`
- `allow-list-dir`
- `allow-read-file`
- `allow-read-file-bytes`
- `allow-write-file`
- `allow-write-file-bytes`
- `allow-create-file`
- `allow-create-dir`
- `allow-rename-entry`
- `allow-delete-entry`
- `allow-move-entry`
- `allow-copy-entry`
